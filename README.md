# Telegram Stars Gifts Monitor 🎁

Монитор для отслеживания новых подарков в Telegram Stars. Бот автоматически проверяет доступные подарки и уведомляет о появлении новых.

## ✨ Возможности

- 🔍 Автоматический мониторинг подарков Telegram Stars
- 🔔 Уведомления о новых подарках
- 📊 Отслеживание лимитированных подарков
- ⏰ Настраиваемый интервал проверки
- 💾 Сохранение истории подарков
